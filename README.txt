# История идей. Общество.

Готовый статический сайт для GitHub Pages.

Файлы:
- `index.html` — главная
- `notes/note-1.html` ... `note-5.html` — заметки
- `style.css` — оформление
- `images/` — фотографии для заметок

Загрузите содержимое этой папки в публичный GitHub-репозиторий и включите GitHub Pages.


Обновлено: переработаны названия и распределение материала по пяти конспектам; убраны основные повторы между Марксом, «Капиталом» и ленинско-советской практикой.
